# **App Name**: Purrfolio

## Core Features:

- Interactive 3D Cat: Implement a 3D model of a cat that users can interact with and that guides users through the site.
- Cat-Guided Navigation: The 3D cat will provide guidance and explanations for each page and tab on the portfolio.
- Portfolio Display: Showcase design projects with descriptions, images, and links.
- Homepage Recreation: Recreate the provided image as the first page of the website, focusing on faithful layout of typographic elements and placement of cat, within the bounds of interactive HTML.
- Animated Cat Movements: Create subtle animations for the 3D cat model, such as head turns, tail wags, and blinking.
- Page Transitions: Design transitions to enhance the user experience as they navigate between portfolio sections. The cat could even instigate them!

## Style Guidelines:

- Primary color: Deep blue (#19456B), reminiscent of a starry night.
- Background color: Slightly lighter desaturated blue (#21496B).
- Accent color: A gentle blue-green (#337578), offering a sense of tranquility and life.
- Font: Based on the image, use 'Poppins', a geometric sans-serif.
- Simple and clean icons for navigation and project categories.
- A grid-based layout for easy content organization and visual balance.
- Smooth transitions and animations for a delightful user experience.
